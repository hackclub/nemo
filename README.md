<h1 align="center">Mnemosyne</h1>

<p align="center">Community analytics and fire department tools for Hack Club.</p>

<p align="center">
  <a href="https://github.com/hackclub/nemo/actions/workflows/ci.yml"><img src="https://github.com/hackclub/nemo/actions/workflows/ci.yml/badge.svg" alt="CI"></a>
  <a href="./LICENSE"><img src="https://img.shields.io/badge/license-MIT-blue.svg" alt="MIT license"></a>
</p>

Mnemosyne is an internal Hack Club tool. It turns Slack metadata into community analytics and gives the fire department tools to moderate the Slack.
